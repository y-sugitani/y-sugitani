## 出来ること

TypeScript/Kotlin/Swift/Scalaを現役で扱っています。(※これら以外の業務でも、おそらく問題になりません)

### 広範囲な業務を行うことができます

フロントエンド、バックエンド、iOS/Androidアプリ、インフラ構築、文化作り、エンジニア採用、チーム運営などできることが多く、
人が少ない状況からどんどん大きくしていく状態が非常に得意です。中規模組織の改革経験もあります。

具体に行えること

- TypeScriptやScalaを用いたバックエンド開発
- Compose Multiplatform(Kotlin)やSwift/Kotlinを用いたiOS/Android開発
- Next.jsを用いたフロントエンド開発
- GCP/AWSを用いたインフラ構築
  - Kubernetes活用やCDN活用なども手慣れています
- スクラム主導やプロジェクト管理、効率的な会議運営

### 綺麗なコードを書くために努力しています

よい道具（言語やツールやDDDなどの手法）を適切に扱い、良い状態を長く続けられるように努力することに注力をしています。DDDは10年以上実践しています。
